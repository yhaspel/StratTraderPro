Run a strategy end to end

This is the full loop for one strategy: read what it does, get its webhook URL and secret, wire the TradingView alert that fires it, enable it, and confirm the first order. Do it once and every subsequent strategy is the same five minutes.

Before you start: two-factor authentication must be enrolled (guide) and a paper broker connected (guide). Without a broker the webhook accepts your alert and then rejects it downstream with NO_BROKER_CONNECTED.

1. Read the strategy description

Open Strategies. Every row shows the strategy name as a link and a one-line summary. Click the name, or View, to open the full description that was uploaded with the strategy.

The detail page shows the description exactly as the author wrote it — what the strategy trades, on what timeframe, and where it is known to be weak.

Read the Known weaknesses section before enabling anything. A Community-tested: No chip means exactly what it says: the Pine bytes were stored and never executed or reviewed by us. You are responsible for what it does with your money.

The same page also shows the Pine source and the strategy's TradingView payload template, so you can check all three against each other in one place.

2. Get the webhook URL and secret

  1. Back on Strategies, click Configure webhook on the row you want.
  2. The modal shows a URL unique to you and this strategy. It is safe to store; it is not a credential on its own.
  3. The webhook secret is shown once. Copy it now into your password manager. If you close the modal without copying it, your only option is Rotate — and rotating immediately invalidates the old secret, which breaks any alert already using it.

3. Copy the payload template

The payload template is the JSON body TradingView will POST. Take it from the TradingView payload template panel on the strategy detail page (or from the webhook modal).

Two rules:

  • Replace only the placeholder in sig with your webhook secret.
  • Leave every {{ … }} marker exactly as it is. TradingView substitutes those at fire time; typing a literal value there means every alert reports the same symbol or size.

Field-by-field detail: The webhook payload template.

4. Create the TradingView alert

  1. Open the chart with the matching Pine strategy applied.
  2. Create an alert on that strategy, not on a bare price condition.
  3. Under Notifications, tick Webhook URL and paste the URL from step 2.
  4. Paste the edited template into the Message box.
  5. Set the alert to Once per bar close unless you specifically want intrabar firing — intrabar alerts fire on ticks that may never close, and each one is a real order.
  6. Save.

Detail, including TradingView's own quirks: Configure your TradingView alert.

5. Enable the strategy

Back on Strategies, flip the Enabled toggle. The app asks you to confirm, because enabling arms live execution: from that moment a delivered alert becomes an order.

Disabling is immediate and needs no confirmation. A disabled strategy still accepts webhook deliveries — they are recorded and then dropped, so you can wire and test an alert before arming it.

6. Confirm the first order

  • Dashboard → Today's fills shows fills as they land.
  • Orders shows every order with its state and, for a rejection, the reason.

If the header reads Offline, the realtime stream is not connected — refresh the page to pull the current state. Orders are still placed normally; only the automatic updating is affected.
