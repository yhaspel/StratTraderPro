Upload your first strategy

StratTraderPro accepts user-uploaded TradingView Pine strategies. Each upload is a bundle of three files. The platform validates the bundle, stores the bytes, and surfaces a per-user webhook URL + secret so TradingView alerts can fire your strategy.

Heads-up: uploaded strategies are not tested by StratTraderPro. We store the Pine bytes verbatim (and never execute them server-side), but you are responsible for reviewing the strategy before enabling live execution. The upload form requires you to acknowledge this risk.

The three-file bundle

Pick a stem (3–64 characters from A–Z, a–z, 0–9, _, or -). All three files share that stem.

FileFilename patternSize limit
Pine script <stem>.pine 64 KB
Description <stem>_Description.txt 16 KB
Webhook payload template <stem>_Webhook.json 16 KB

The pine script must declare its TradingView Pine version within the first 64 bytes:

//@version=5
strategy("Demo Strategy", overlay=true)
…

The webhook JSON

This file is the template we'll show you when you copy the TradingView alert config. It must be a JSON object that includes the following top-level keys:

  • strategy — your strategy slug or any string.
  • action — typically "buy", "sell", or "exit".
  • symbol — TradingView usually fills this with {{ticker}}.
  • qty — number of contracts/shares.
  • order_type — "MKT", "LMT", etc.

You can add other keys (idempotency_key, account_id, anything else) — they'll be passed through to the broker layer.

The wizard

  1. Select files — drop in all three. Filenames are validated live; mismatches show inline.
  2. Review — confirm the parsed description preview and the JSON keys are what you expect.
  3. Acknowledge & submit — check the "I understand uploaded strategies are not tested" box and submit.

What happens next

  1. Your strategy appears in Strategies with a "User-uploaded" badge.
  2. Open Configure webhook to view your unique webhook URL and one-time HMAC secret. Copy the secret now — it won't be shown again.
  3. Paste the URL + secret into your TradingView alert config (the Copy TradingView template button does this for you).
  4. StratTraderPro validates inbound alerts against your stored JSON Schema before sending orders downstream (M04).
